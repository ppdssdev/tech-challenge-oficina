# Ícones da capa de arquitetura

O diagrama `oficina-arquitetura-aws.svg` é um arquivo vetorial independente: os ícones estão incorporados no SVG, sem dependência de CDNs, scripts ou carregamento externo. O layout, as conexões e os textos representam a topologia de staging descrita no README. O SVG é a fonte editável do desenho.

## Fontes

- **AWS Architecture Icons**: ícones de EC2, RDS, ECR, VPC, Lambda, Systems Manager, S3, IAM, API Gateway e Secrets Manager, obtidos no pacote oficial de 31/07/2026. [Página e condições de uso](https://aws.amazon.com/architecture/icons/).
- **Devicon**: Docker, Kubernetes, Spring, Terraform, PostgreSQL, Prometheus, Grafana e GitHub Actions. Ícones originais, com licença MIT reproduzida abaixo.
- **CNCF Artwork**: [ícone K3s](https://github.com/cncf/artwork/blob/main/projects/k3s/icon/color/k3s-icon-color.svg). [Orientações de uso de marcas e logotipos](https://github.com/cncf/artwork#cncf-artwork).

As marcas identificam os produtos utilizados; pertencem aos respectivos titulares. Os ícones foram redimensionados proporcionalmente, preservando as cores. Identificadores internos de SVG foram ajustados para evitar colisões entre gradients e elementos.

Pacote AWS: [download oficial](https://d1.awsstatic.com/onedam/marketing-channels/website/public/shared/architecture-icon-release/Icon-package_07312026.5846e92413caa21490223536cc97f1269e44fa92.zip).

Versão Devicon: [`32fe1d3b3f36ad11f90ab94f7db59738139c2bf6`](https://github.com/devicons/devicon/tree/32fe1d3b3f36ad11f90ab94f7db59738139c2bf6).
